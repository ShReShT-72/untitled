# IPL AI Auction Game

A browser game where one human controls one IPL franchise in a player auction against nine AI franchises.

**Status:** Stage 2 specifications approved. Application code not yet built.

## Specifications
- Requirements, design and tasks: .kiro/specs/ipl-ai-auction-game/
- Project audit: project-audit.md

## Sample data
- Mock_list.txt is the owner's mock auction list, used as sample data. It is not official.
- .kiro/specs/ipl-ai-auction-game/data/mock-auction-list.csv is generated from it by 	ools/format-mock-list.ps1.
